# 🚀 أهلاً بك في ملفي الشخصي! أنا أحمد

*   **التخصص:** تحليل البيانات (Data Analysis) | تطوير ذكاء الأعمال (BI Development).

*   **التركيز الحالي:** تطوير مهارات متقدمة في تحليل البيانات باستخدام SQL, Python, Power BI, وTableau.
